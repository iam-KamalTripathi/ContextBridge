### 🎯 **How to Use:**

1. **Open your browser** and go to: http://localhost:3000
2. **Register/Login** to create an account
3. **Take the Quiz** to get career recommendations
4. **Use the Chatbot** for personalized career advice
5. **View your Dashboard** for quiz history and results

### 🔧 **API Endpoints Available:**

- `GET /api/health` - Check API status
- `GET /api/quiz` - Get quiz questions
- `POST /api/submit-quiz` - Submit quiz answers
- `POST /api/chat` - Send messages to AI chatbot
- `GET /api/user/history` - Get user's quiz history
- `POST /api/register` - Register new user
- `POST /api/login` - Login user
- `POST /api/verify-token` - Verify authentication

### 🛠️ **Technical Configuration:**

- **Database**: SQLite (career_compass.db)
